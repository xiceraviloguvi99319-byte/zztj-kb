# 方法说明 / Methodology

## 流水线

```
维基文库校刊本原文
  → 文本清洗（去格式标记、统一异体字）
  → 胡三省音注处理（〔〕内校勘增补字照常标注，()内被替换原文不标）
  → 19 类实体标注（人名/地名/邦国/官职/时间/年号/身份/氏族/名物/族群 + 4 类事件触发动词）
  → 事件抽取（每卷按编年排序，id 形如 001-W23-01）
  → JSON 落盘 + 人工抽检
```

## 标注规范

19 类实体符号与 5 条通鉴特有规则（年号 vs 时间、邦国 vs 地名、人名消歧、臣光曰处理、胡注处理）见 [annotation-spec.md](annotation-spec.md)，v1.0，由史记知识图谱（shiji-kb）方法论迁移而来。

## 质量控制

- 每卷 4 件套验收：清洗文本、校刊记、标注版 Markdown、事件 JSON（可解析、id 唯一）
- 失败卷自动重试一次，两次失败转人工
- 全书 294 卷完成后统一事件 `type` 词表

## 进度

自动化流水线每日推进，实时统计见仓库根目录 `stats.json`。
