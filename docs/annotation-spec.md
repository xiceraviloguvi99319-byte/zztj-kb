## 二、通鉴特有规则

### R1 年号 vs 时间
- "威烈王二十三年" → 〖*威烈王二十三年〗（年号，含帝王名+序数）
- "三年"、"明日"、"夜" → 〖%时间〗
- 干支"戊寅"单独出现 → 〖%戊寅〗；括号内西元纪年是今人增补，**不标**

### R2 邦国 vs 地名
- "晉"作政治实体 → 〖#晉〗；"晉陽"作城邑 → 〖=晉陽〗
- "三晉"指魏趙韓三国 → 〖#三晉〗

### R3 人名消歧（章内）
- 智瑤=智伯=智襄子 → 同一实体，首现用全名 〖@智瑤〗，后文"智伯"标 〖@智伯〗 并记别名
- 臣光曰/太史公曰 → 〖@司馬光〗/〖@司馬遷〗（作者自称，还原真名）

### R4 臣光曰/太史公曰
论赞部分单独成段，标注人物/典籍引用，事件提取时记为"评论"类型不计入史实事件

### R5 胡注处理
本试点用维基文库校刊本，"〔〕"内为校勘增补字，照常标注；"( )"内为被替换原文，**不标**

## 三、事件提取（编年体特化）
- 每条以年份为天然主键：事件ID = 卷号-年号-条目序号（如 001-*威烈王二十三年-02）
- 不做跨章对齐（已按年排列）；同一年的多条目记并发关系
- 臣光曰/太史公曰 → 类型=论赞，不参与年代推断
- 纪年：通鉴自带年号+干支+西元对照，年代推断工作量远小于史记

## 四、质量门
- Lint：去标记后文本必须与原文逐字相同
- 试点目标：遗漏率<15%，误标率<10%（第一轮粗标可接受）
