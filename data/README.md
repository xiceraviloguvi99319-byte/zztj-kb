# 数据说明 / Data

`sample/` 下为 5 卷示例事件数据（卷 1–5），与全量数据同格式。

## 字段

| 字段 | 说明 |
|---|---|
| `volume` | 卷号（001–294） |
| `year_label` / `year_bce` / `year_ganzhi` | 纪年（年号/公元前年份/干支） |
| `events[].id` | 事件 id，形如 `001-W23-01`（卷-纪年-序号） |
| `events[].type` | 事件类型，如 `政治/分封`、`军事/战争` |
| `events[].desc` | 事件描述（一句话） |
| `events[].人物` 等 | 参与实体（人物/地点/邦国…，按卷实际出现） |
| `events[].related_lunzans` | 相关的"臣光曰"论赞 |

全量数据（294 卷完成后发布）将按相同结构组织。数据许可：CC-BY-4.0。
